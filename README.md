# 📦 Inventory Management System (Web)

A responsive Inventory Management System built using HTML, CSS, and JavaScript. This project allows users to manage products with a clean dashboard and provides complete CRUD (Create, Read, Update, Delete) functionality.

---

## 🚀 Features

- ➕ Add Product
- 📋 View Products
- ✏️ Edit Product
- 🗑️ Delete Product
- 🚫 Duplicate Product ID Validation
- 📊 Dashboard
  - Total Products
  - Total Stock
  - Low Stock Products
  - Total Inventory Value
- 💾 Local Storage Support (Data persists after page refresh)
- 🎨 Responsive User Interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
